# Quant

Учебное e-commerce приложение магазина усов. Проект собран как SPA на React: в нем реализованы каталог товаров, карточка товара, авторизация, профиль пользователя, корзина, оформление заказа, страница успешной покупки и история заказов.

## Стек

- React 19, TypeScript, Vite
- React Router
- Redux Toolkit, RTK Query
- json-server как моковый backend
- Tailwind CSS
- Radix UI
- React Hook Form, Zod
- React Testing Library, Jest, Playwright
- react-hot-toast, react-to-print, react-credit-cards-2
- embla-carousel-react для слайдера

## Реализовано

- UI-kit по макету: кнопки, поля, чекбоксы, радио-группы, select, dialog/modal, переключатели, иконки.
- Роутинг приложения и защищенные страницы.
- Главная страница-каталог на реальных данных с сортировкой, поиском и серверной пагинацией json-server.
- Фильтрация каталога через query-параметры RTK Query: категория, стиль, густота, boolean-фильтры, диапазон цены, сортировка и поиск.
- Мобильный сценарий каталога: отдельный экран категорий, экран товаров выбранной категории и отдельный экран фильтров.
- Страница товара с реальными данными, рейтингами, хлебными крошками, отзывами и кнопкой добавления в корзину.
- Авторизация и регистрация через API, `authSlice`, хранение токена в `localStorage`.
- Формы логина, регистрации и редактирования профиля на React Hook Form и Zod.
- Восстановление пароля на странице логина через модальное окно.
- Профиль пользователя, редактирование данных, выбор языка и email-уведомления.
- Корзина на данных из Redux store: счетчик товаров в шапке, изменение количества, удаление через подтверждение.
- Оформление заказа `/checkout`: способы оплаты, сохраненные карты в `localStorage` по id пользователя, добавление новой карты, доставка курьером или в пункт выдачи, выбор города и ПВЗ, валидация обязательных полей.
- Успешный заказ `/success`: перенос данных заказа из checkout, печать страницы, ссылка на историю заказов.
- История заказов `/profile/orders`: загрузка заказов пользователя через API и раскрывающийся список на Radix Collapsible.
- Toast-уведомления для успешных и ошибочных пользовательских действий.

## API И Данные

Моковый backend работает на `json-server`. Vite проксирует запросы `/api` на `http://localhost:3001`.

Основные сущности в `db.json`:

- `products`
- `users`
- `cart`
- `orders`
- `ratings`
- `pickupPoints`

Для каталога используется серверная пагинация json-server:

```text
/products?_page=1&_limit=12
```

Общее количество товаров читается из заголовка `X-Total-Count`.

## Запуск

Установить зависимости:

```bash
npm install
```

Запустить моковый backend:

```bash
npm run server
```

В отдельном терминале запустить frontend:

```bash
npm run dev
```

Приложение будет доступно по адресу из вывода Vite, обычно `http://localhost:5173`.

## Проверки

Сборка:

```bash
npm run build
```

Линтинг:

```bash
npm run lint
```

Jest и React Testing Library:

```bash
npm run test
```

E2E-сценарий Playwright:

```bash
npm run dev -- --host 127.0.0.1 --port 5174
npm run test:e2e
```

E2E-тест мокает backend-ответы через Playwright routes и не записывает тестовые заказы в `db.json`.
